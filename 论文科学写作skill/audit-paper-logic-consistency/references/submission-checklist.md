# 投稿前内容自检

来源：《论文科学写作.docx》图片34–41（课件149–153、164–166页）。原课件没有提供各期刊格式要求，必须另读用户的实际目标模板。

## 四轮修改

1. 研究主线：检查Problem、Gap、Idea和Contribution是否成立。
2. 结构：检查章节、段落是否围绕主线组织，信息顺序是否合理。
3. 证据：检查每个Claim是否有直接Evidence、实验是否公平、结论是否过度。
4. 语言：最后处理语法、词汇、时态、冠词、标点和格式。

## 按顺序自检

- 一页纸主线：重写Problem、Gap、Idea、Claims和Evidence。核心Idea不依赖模块名仍可解释，全文围绕清晰问题展开。
- 跨章：核对Title、Abstract、Introduction、Experiments及Conclusion。标题准确、具体、可检索；摘要背景不过长，明确缺口、核心方法和关键结果，结论不超过正文证据。
- 段落：标注主题、依据及上下文关系，删除或合并无明确功能的内容，避免只靠连接词制造逻辑。
- 相关工作：形成研究路线，说明已有方法为什么不够，检查最接近工作与本文的真实差异。
- 方法：先定义问题、输入、输出、目标和约束；提供总体框架；每项设计有动机，Gap与Solution之间有合理依据；公式、符号和假设清楚一致。
- 实验：每个核心Claim有直接证据；强基线和公平比较充分；消融检验明确假设；结果有解释，报告必要局限和失败情况。
- 图表：每张核心图表支持明确RQ，标题或图注说明对象和条件，坐标、单位、图例完整，最终尺寸可读。
- 引用：逐条核对关键引用是否真实支持正文表达；不可访问时记录未核实，不声称完成验证。
- 符号：统一公式、缩写、变量和单位，缩写首次定义；模块名在正文、图表、消融中一致。
- 语言：最后压缩冗余与语法修改，保留限定条件和证据强度。
- 格式：用户提供目标期刊或会议要求且授权格式检查时，检查篇幅、图表、参考文献及匿名要求；没有模板时仅列待核实项，不宣称合规。

## 从审稿意见定位问题

| 意见 | 论证环节 | 核验重点 |
| --- | --- | --- |
| 动机不清晰 | Problem / Gap | 研究问题及价值是否具体 |
| 新颖性增量有限 | Idea | 核心增量及与已有工作的区别 |
| 方法缺少依据 | Gap–Method | 设计动机和依据是否明确 |
| 比较不足 | Evidence | 强基线及公平性 |
| 鲁棒性无支持 | Claim–Evidence | 是否超过已测试范围 |
| 论文难以理解 | Structure | 总体框架、定义、段落主线 |

此表用于诊断和修改，不构成独立审稿回复技能。需要作者核实的问题不能通过措辞伪造解决。
