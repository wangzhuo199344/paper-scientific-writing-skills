# 学术语言与段落结构

## 执行约束

- 先读取用户提供的当前稿件、文献、数据和目标要求；只检查已提供的部分，不将未提供材料判定为论文缺失。
- 默认使用精炼、连贯的中文学术表达；遵守用户指定的语言、长度、范围和格式。只要求正文时只输出正文。
- 不编造文献、数据、实验结果、创新性或统计显著性；区分观测、解释、已验证结论和待验证假设。证据不足时标为待核实。
- 将课件原则转为任务流程，按研究类型调整，不把算法实验模板强加给理论、实证或定性论文。
- 先完成现有材料能支持的工作。要求修改 Word 等文件时使用环境适用的文档工具，保留格式并验证；本技能自身不包含文件渲染工具。

## 按需参考

执行本技能时读取 [references/language-checklist.md](references/language-checklist.md)，其中记录原文规则、模板和使用边界。

## 工作流程

1. 读取当前文字和上下文，记录事实、数字、单位、条件、引文、术语和主张强度。明显逻辑或证据问题先标出，不能靠润色伪装修复。
2. 给每段标注主题或主张、支持依据或解释、与上下文和主线的关系。删除后不影响逻辑的段落需要合并、删除或明确其功能，保留必要定义和复现信息。
3. 建立真实的对比、因果、递进、条件、一般到具体或问题到解决方案关系。However、Therefore、Moreover及中文连接词只能标记关系，不能制造关系；缺少推理桥梁时补可支持的解释，未知事实则标待补。
4. 明确句子的主语、动作和对象，一个句子不同时承担过多不同逻辑任务。简洁不是一律短句，而是提高单位文字的信息量。
5. 删除套话和可省冗余，按 [references/language-checklist.md](references/language-checklist.md) 检查直接表达、证据措辞及可检验形容词。
6. 保持证据强度：谨慎使用prove、demonstrate、show、suggest、indicate，依实际证据选词；significantly或“显著”表示统计含义时需要相应依据。不机械按词建立固定证据等级。
7. 统一同一概念、符号、缩写、模块、指标和单位，缩写首次出现时定义。术语替换不能改写方法含义。
8. 处理跨位置重复：正文不复读图表全部数字，引言与相关工作分工，摘要、贡献和结论选择不同信息粒度，公式前后不重复相同过程。保持强调所需的必要重复。
9. 最后检查语法、词汇、时态、冠词、标点及格式；不要声称语言修改解决了尚未处理的研究问题。

## 默认交付

给可直接替换的修订文字；需要说明时附少量实质调整与待核实项。用户仅要求文字时不附说明，必要未知信息用明确占位符保留。

## 完成检查

数值、条件、引文和结论强度是否保留？每段有明确功能和真实逻辑桥梁？是否为了流畅删掉必要限定，或把可能解释升级为确定结论？
