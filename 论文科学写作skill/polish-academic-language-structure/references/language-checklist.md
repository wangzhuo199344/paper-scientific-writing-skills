# 语言与段落检查

来源：《论文科学写作.docx》图片27–33（课件126–128、133–135、141页），图片34（149页）及38（153页）。

## 直接表达

| 冗余表达 | 可采用的直接表达 |
| --- | --- |
| It can be clearly seen from Fig. 3 that… | Fig. 3 shows… |
| Due to the fact that… | Because… |
| In order to… | To… |
| It is worth noting that… | 直接陈述值得注意的事实 |

依据语境修改，不把简洁机械理解为句子短。

## 将评价词转成可检验内容

- efficient：时间、内存、参数量、能耗或通信开销中的哪一项，在什么测量条件下？
- robust：针对什么扰动，在什么范围内，结果如何？
- superior：相对哪些基线，哪些指标，使用什么评价协议？
- significantly：是否有统计显著性的依据，而非仅数值更大或更小？

## 建立逻辑桥梁

不要仅写“已有方法存在局限，因此增加时序模块”。先说明已有处理遗漏了近期历史，再说明新设计怎样表示历史，最后说明用何种对照检验其作用。仅在材料支持时补入这些事实，否则标为待补。

## 修改顺序

研究主线 → 结构 → 证据 → 语言。检查科学逻辑和证据链已稳定，再做语言优化；单纯英文润色不能解决根本逻辑问题。
