## 设计论证

按问题与所需能力解释设计，而非只按操作顺序介绍模块。课件以DCRNN展示：复杂空间依赖对应有向空间关系表达，非线性时间动态对应刻画时间演化，长期预测对应多步预测组织。这个例子用于理解论证结构，不要求用户采用该方法，也不替代原论文核实。

## 公式审查表

| 项目 | 检查内容 |
| --- | --- |
| 目的 | 定义、推导或计算的必要性 |
| 符号 | 含义、首次定义、重复使用是否冲突 |
| 假设 | 成立条件是否显式说明 |
| 依据 | 理论、定义或文献是否支持关键式 |
| 对应关系 | 与文字、算法和实际实现是否一致 |
| 复现信息 | 省略步骤后是否仍可理解和复现 |

框架图用箭头表示依赖；不同线型应在图注说明。区分训练与推理的数据流和参数流。
