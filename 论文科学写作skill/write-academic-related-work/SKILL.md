# 相关工作与研究定位

## 执行约束

- 先读取用户提供的当前稿件、文献、数据和目标要求；只检查已提供的部分，不将未提供材料判定为论文缺失。
- 默认使用精炼、连贯的中文学术表达；遵守用户指定的语言、长度、范围和格式。只要求正文时只输出正文。
- 不编造文献、数据、实验结果、创新性或统计显著性；区分观测、解释、已验证结论和待验证假设。证据不足时标为待核实。
- 将课件原则转为任务流程，按研究类型调整，不把算法实验模板强加给理论、实证或定性论文。
- 先完成现有材料能支持的工作。要求修改 Word 等文件时使用环境适用的文档工具，保留格式并验证；本技能自身不包含文件渲染工具。

## 按需参考

执行本技能时读取 [references/source-guidance.md](references/source-guidance.md)，其中记录原文规则、模板和使用边界。

## 工作流程

1. 从研究问题和方法确定综述范围。阅读引用的原始论文或用户提供的相关内容，建立“文献—问题—假设—能力—边界—证据位置”表。只有标题或摘要时限制判断范围。
2. 按解决思路、信息使用方式或成立假设分类；组织为“分类 → 代表性工作 → 比较 → 适用边界 → 本文定位”，避免仅按作者或年份串联。
3. 在统一维度比较 Problem、Assumption、Capability、Boundary。先判断是否解决同一问题；不同设置的性能不得直接排名。
4. 检查引用是否覆盖直接相关的经典工作、最接近工作和代表近期水平的工作。资料不足时列出检索任务。需要检索时核实原始论文和出版信息，不生成虚假作者、年份、DOI或编号。
5. 正面比较最接近工作：问题是否相同，输入信息、假设、技术路线有何不同，新增的是能力、效率、适用范围还是认识，哪些差异在本文得到验证。
6. 忠实描述已有能力，不通过弱化或曲解他人方法制造缺口。将“研究较少”改成有依据的边界与具体后果；无法核实的边界保留明确标记。
7. 与引言分工：引言用紧凑文献建立研究动机，本节用比较说明研究版图和定位。避免重复同一组文献的完整描述。

## 默认交付

给出可直接使用的相关工作正文；审查任务给“研究路线／代表文献与依据／问题与假设／能力与边界／本文差异与证据”的比较表，附必要的待核实引用。

## 完成检查

检查分类有无比较意义，最接近工作是否明确，各边界是否有依据，本文增量是否连接到实验或论证，而非只写作者做过什么。
