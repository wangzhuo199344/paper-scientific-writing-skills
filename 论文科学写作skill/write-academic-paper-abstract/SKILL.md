# 论文摘要

## 通用约束

- 以用户提供的当前稿件、数据、文献和投稿要求为依据。先读取相关内容，不用记忆中的旧版本替代当前材料。
- 默认中文学术表达，使用具体、精炼、连贯的段落；用户指定语言、长度、格式和范围时优先遵守。
- 不编造数值、文献、对比优势、因果关系或创新性。区分已有证据、作者解释与待验证设想；证据不足时明确标为待核实。
- 先完成现有材料能支持的工作；只有缺失信息会影响核心结论时才提出必要问题。不得把用户未回答的内容当作事实。
- 用户只要求文字时直接输出文字；要求修改文件时使用当前环境适用的文档技能，保留原格式并验证交付文件。
- 不强行套用固定论文模板。实证、理论、算法及定性研究均可使用，以研究自身的证据类型和学科规范为准。

## 工作流程

1. 从当前稿件建立事实清单：对象与问题、缺口、核心思想、方法、样本与时段、主要结果、结论及边界。缺少全文时只使用给定材料，不填补未提供的数据。
2. 三次压缩：先保留Problem、Gap、Idea、Method和Evidence；再保留最能支持核心Claim的结果；最后删除不影响主线的背景、实现细节和次要结果。
3. 优先回答现有研究缺少什么、本文改变了什么、验证得到什么。每句话承担明确的信息功能，避免宏观背景占据多数篇幅。
4. 选择最能支持核心贡献的1–3项关键结果，必要时给出适用边界。实证研究不必强行声称提出新算法；无数字的理论或定性研究给出具体可核实结论。
5. 检查数值、单位、比较基准、样本口径、统计显著性及不确定性；不把“相关”写成“导致”，不将条件性结果扩展为普遍优势。
6. 按目标期刊字数及结构要求写作。无指定结构时采用连贯单段；不拼接各章节首句，不只写“实验表明有效”。
7. 中英文处理时逐项核对对象、时段、样本、方法、数值、单位、结果强度和边界。选用用户指定的权威版本，未指定时标出冲突并给出基于正文的修正，不擅自选择数值。

## 默认输出

给出可直接使用的摘要；修改或比较任务追加简短的重要调整与待核实项。用户只要摘要时不附评论。字数限制存在时实际核验字符或单词数，保留用户要求的计数口径。

## 交付检查

缺口、思想与关键结果是否具体？所有数字是否与正文对应？中英文是否信息等价？是否省略了会改变结论的限定条件？
