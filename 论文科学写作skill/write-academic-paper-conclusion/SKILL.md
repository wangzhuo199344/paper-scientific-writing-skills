# 论文结论与局限

## 执行约束

- 先读取用户提供的当前稿件、文献、数据和目标要求；只检查已提供的部分，不将未提供材料判定为论文缺失。
- 默认使用精炼、连贯的中文学术表达；遵守用户指定的语言、长度、范围和格式。只要求正文时只输出正文。
- 不编造文献、数据、实验结果、创新性或统计显著性；区分观测、解释、已验证结论和待验证假设。证据不足时标为待核实。
- 将课件原则转为任务流程，按研究类型调整，不把算法实验模板强加给理论、实证或定性论文。
- 先完成现有材料能支持的工作。要求修改 Word 等文件时使用环境适用的文档工具，保留格式并验证；本技能自身不包含文件渲染工具。

## 按需参考

执行本技能时读取 [references/source-guidance.md](references/source-guidance.md)，其中记录原文规则、模板和使用边界。

## 工作流程

1. 从当前正文提取研究问题、核心思想、主要证据和适用条件，核对摘要、贡献和结果的口径。
2. 回答四项：解决什么问题，采用什么核心思想，得到什么主要结论，结论的适用范围和局限是什么。
3. 按发现及学术意义组织，不按章节目录回顾。必要时保留能支持主要结论的关键数值、单位和条件，不重复所有方法步骤与实验数字。
4. 将结论限定在已验证对象、场景和范围内。观察关联不能升级为因果，机制解释不足不能写成已证明机制。
5. 与摘要分工：摘要压缩完整研究，结论突出证据支持的最终认识及边界，避免简单复制或仅换词。
6. 报告实际局限；未来工作仅在用户或目标规范需要时提出，并与局限对应。未来计划不当作已经取得的结果。
7. 若发现跨章节冲突，指出来源并修正有确定依据的表述；无法裁决的数值标为待核实，不擅自挑选。

## 默认交付

交付可直接使用的结论；审查时附“结论／正文证据／适用范围／修改建议”，用户只要正文时省略分析。

## 完成检查

是否回答四项核心内容？是否照搬摘要或新增无证据主张？是否保留改变结论含义的限定条件？局限是否来自实际研究？
