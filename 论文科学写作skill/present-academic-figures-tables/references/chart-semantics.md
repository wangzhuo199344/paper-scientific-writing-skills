# 图表统计含义

来源：《论文科学写作.docx》图片21–25（课件119–123页），图片37（152页）。

## 箱线图

- 箱体从Q1到Q3表示约中间50%的数据，箱内线通常表示中位数。
- 课件使用1.5×IQR规则；须延伸到规则范围内最远观测值，而非必然落在理论边界。IQR = Q3 − Q1。
- 范围外单独显示的点是潜在离群观测，不自动等于错误数据。不同四分位数算法及须定义可能产生不同结果，图注需说明实际约定。

## 小提琴图

- 纵向位置为数据取值，横向宽度表示该值附近的估计密度；越宽表示附近数据相对集中。
- 形状依赖样本量、核密度带宽和归一化方式；不能直接把宽度当样本数，通常也不直接标离群点。
- 中位数线是课件自定义标记，不是所有小提琴图固定元素。说明实际叠加统计量。

## 累积分布

- CDF为F(x)=P(X≤x)，纵轴是累计比例而非密度；横轴是取值或阈值及其单位。
- ECDF按实际样本形成阶梯；密集样本可看起来近似连续。解释某阈值时报告不超过该值的比例。
- 课件示例的F(4)=0.8不能迁移为用户结果；必须从真实样本读取或计算。

## 框架与流程

模块名说明功能，箭头方向说明依赖，不同线型在图注定义。课件例子以实线表示推理数据流、虚线表示校准阶段参数提供；实际论文按自己的过程标注，不强制采用此约定。

## 图注要素

说明比较对象与条件、坐标和单位、图例、统计量与必要参数、重复或样本单位。双栏或单栏最终排版尺寸下检查可读性，不只检查放大后的截图。
