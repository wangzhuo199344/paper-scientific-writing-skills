# 研究问题与证据设计

来源：《论文科学写作.docx》图片13–17（课件102–105、107页），图片36（151页）及41（166页）。

| 问题 | 常见证据 |
| --- | --- |
| 方法是否有效 | 与强baseline或SOTA进行主要任务比较 |
| 为什么有效 | 消融、机制分析、案例分析 |
| 在什么条件下有效 | 场景、噪声、数据规模、参数分布变化 |
| 付出什么成本 | 延迟、吞吐、FLOPs、参数量、显存、通信或能耗 |
| 结论是否可靠 | 多次运行、均值与方差、置信区间、统计检验、跨数据集验证 |

注意：原课件107页的局部示例将效率、稳定性另标为RQ3、RQ4；102–103页分别用RQ4、RQ5描述成本、可靠性。保留问题含义，按当前论文统一编号。

消融不仅是机械删除模块，必须说明设计假设、受控改变、观测及解释。实验比较不足应检查强基线和公平性；鲁棒性主张无支持应检查结论是否超过实验覆盖条件。
